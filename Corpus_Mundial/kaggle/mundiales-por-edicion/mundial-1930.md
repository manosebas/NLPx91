# Copa Mundial de Fútbol de 1930

La Copa Mundial de Fútbol de 1930 se disputó en Uruguay. Uruguay se coronó campeón al vencer a Argentina en la final. Estados Unidos terminó en tercer lugar y Yugoslavia en cuarto puesto.

## Datos de la edición

| Campo | Valor |
|---|---|
| Año | 1930 |
| País sede | Uruguay |
| Campeón | Uruguay |
| Subcampeón | Argentina |
| Tercer lugar | Estados Unidos |
| Cuarto lugar | Yugoslavia |
| Equipos participantes | 13 |
| Partidos jugados | 18 |
| Goles totales | 70 |
| Asistencia total | 590,549 |
