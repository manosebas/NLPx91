# Código de referido al crear cuenta

El código de referido es un código opcional que puede ingresar el usuario al crear su cuenta, si fue invitado por un amigo que ya tiene cuenta en 91.

El campo aparece como:

- "Código de referido (opcional)"
- O: "¿Tienes un código de algún amigo?"

## El código es opcional

El usuario no está obligado a ingresar un código de referido para crear su cuenta. Si no tiene código, puede dejar el campo vacío y crear su cuenta normalmente.

## Beneficio de usar un código de referido

Si el usuario ingresa un código de referido válido, recibe monedas gratis al confirmar su cuenta.

Estas monedas se pueden usar para:

- Inscribirse a torneos
- Comprar ítems en la tienda

## Si el usuario no tiene código de referido

Si el usuario no tiene código de referido, puede dejar el campo vacío. Después de crear la cuenta, podrá ver su propio código de referido en su perfil para invitar a otras personas.

## Preguntas frecuentes

**¿El código de referido es obligatorio?**
No. El código de referido es opcional.

**¿Qué pasa si ingreso un código de referido?**
Si ingresas un código de referido válido, recibes monedas gratis al confirmar tu cuenta. Puedes usar esas monedas en torneos o en la tienda.

**¿Qué pasa si no tengo código de referido?**
Puedes dejar el campo vacío. Igual podrás crear tu cuenta y luego ver tu propio código de referido en tu perfil.
