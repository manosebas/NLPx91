# Flujo para invitar amigos con referido

Existen dos formas de invitar amigos a 91: compartir el **link** o compartir el **código**.

## Flujo usando el link de referido

1. Entrar a https://www.noventayuno.com/perfil
2. Ir a la sección de referidos.
3. Copiar o compartir el link personal.
4. Enviar el link al amigo.
5. El amigo abre el link.
6. El amigo crea su cuenta.
7. El código se aplica automáticamente.
8. El amigo recibe monedas gratis al registrarse con el referido.
9. El usuario que invitó acumula un referido en su contador.

## Flujo usando el código de referido

1. Entrar a https://www.noventayuno.com/perfil
2. Ir a la sección de referidos.
3. Copiar el código personal.
4. Enviar el código manualmente al amigo.
5. El amigo entra a la página de creación de cuenta.
6. El amigo ingresa el código durante el registro.
7. El amigo crea su cuenta.
8. El amigo recibe monedas gratis al registrarse con el referido.
9. El usuario que invitó acumula un referido en su contador.

## Recomendación

Compartir el **link** es más simple: el código se aplica solo. El código manual es útil cuando se quiere enviar por mensaje sin link clickeable.

## Preguntas frecuentes

**¿Qué gano yo por invitar amigos?**
Puedes desbloquear recompensas y reclamar monedas mientras más amigos se registren con tu referido.

**¿Qué gana mi amigo si usa mi referido?**
Cada persona que se registre con tu referido recibe monedas gratis para empezar.
