# Código y link de referido

Cada usuario tiene un código personal y un link personal de referido para invitar amigos a 91. Ambos están disponibles en la sección de referidos dentro del perfil.

URL: https://www.noventayuno.com/perfil

## Código personal de referido

El código personal de referido es un código único que identifica al usuario que invita.

### Cómo funciona el código

- El usuario copia su código y lo envía manualmente a otra persona.
- La persona invitada debe ingresar ese código **durante el registro** para que el referido se aplique.

## Link de referido

El link de referido es un enlace personal que el usuario puede compartir.

### Cómo funciona el link

- Cuando una persona usa el link, es redirigida directamente a la página de creación de cuenta.
- El código de referido se aplica **automáticamente** durante el registro.

## Diferencia entre código y link

| Compartir | Cómo se aplica el referido |
|---|---|
| Código | El amigo debe ingresarlo manualmente al crear su cuenta |
| Link | El código se aplica automáticamente al crear la cuenta |

## Beneficio para la persona invitada

Cada persona que se registre usando un referido recibe **monedas gratis** para empezar. Estas monedas sirven para participar en torneos o usar funciones disponibles dentro de la plataforma.

## Beneficio para quien refiere

El usuario que invita puede desbloquear recompensas y reclamar monedas mientras más amigos se registren con su referido. Ver: recompensas por referidos.

## Preguntas frecuentes

**¿Dónde veo mi código de referido?**
Puedes verlo en la sección de referidos dentro de tu perfil.

**¿Cómo comparto mi código de referido?**
Puedes copiar tu código y enviarlo manualmente a tus amigos. Ellos deberán ingresarlo al crear su cuenta.

**¿Cómo comparto mi link de referido?**
Puedes copiar o compartir tu link desde la sección de referidos. Si tu amigo usa ese link, el código se aplicará automáticamente al crear su cuenta.

**¿Cuál es la diferencia entre código y link de referido?**
El código debe ingresarse manualmente durante el registro. El link redirige a la página de crear cuenta y aplica el código automáticamente.

**¿Qué gana mi amigo si usa mi referido?**
Cada persona que se registre con tu referido recibe monedas gratis para empezar.

**¿Los referidos cuestan monedas?**
No. Invitar amigos con tu código o link de referido no cuesta monedas.
